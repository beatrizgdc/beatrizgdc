## O que eu faço

- Sustentação de ambientes AWS multi-account (Organizations, Control Tower)
- Resposta a incidentes e tratamento de alertas de segurança (GuardDuty, WAF)
- Infraestrutura como código com Terraform
- Pipelines de CI/CD com AWS CodePipeline e CodeDeploy
- Observabilidade com Datadog, Grafana e CloudWatch (dashboards, Logs Insights, alarms)
- Migração de workloads entre contas AWS (EC2, RDS, ECR, ECS, ALB, CloudFront, Route 53)
- FinOps: rightsizing de task definitions no ECS/Fargate, redução de até 75% dos recursos alocados por task
